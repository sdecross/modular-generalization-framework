# modular-generalization-framework
_Innovation in methodological approaches to fear generalization_

This repository will imminently contain data and code supporting the manuscript with the working title:
Advancing Precision Psychiatry through Innovation in Translational Mechanism Characterization: Capturing Complex Learning Patterns in Fear Generalization

Study 1 in this manuscript investigated fear generalization as part of a larger study conducted at Harvard University examining mechanisms linking childhood trauma with psychopathology, for which Dr. DeCross served as Co-PI. The OSF repository for the larger study may be found at osf.io/qem7s, with additional shared information at osf.io/cpyzt.
